### Runs completely inside your browser. Open `tracker.html` and start logging habits right away.

## Key Features

* Go through Dates and Months without any hassle.
* Historical days stay locked so past performance cannot be edited after the fact. **NO CHEATING**.
* From the source code you can add recurring tasks of your wish so you don't have to write them daily.
* Tasks left pending when midnight passes automatically flip to failed status. (follows local device timezone, so resets exactly at 12A.M of your location).
* Interactive month-by-month report showing completion percentages and task statistics.
* **Clean Markdown Export**: Download customizable date ranges into structured `.md` files with total efficiency metrics included.

## Data Persistence & Storage

All logs are saved directly in your browser's `localStorage` under the key `cyberTrackerData`. So no login/signup WORRIES.

**Your data stays put unless:**

* You clear your browser's cookies, or site data. (Infact it even survives cache clears in most cases)
* You open the file in Incognito or Private mode.
* You switch to a different web browser.
* You log into a different OS user account or move to a new device.

> **Tip:** Use the Markdown Export tool regularly to back up your history before clearing browser data or switching devices.
